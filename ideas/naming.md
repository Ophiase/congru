# Naming

**[defined]** The project is **congru**: crate `congru`, Python package
`congru`, C prefix `congru_`.

Two shapes are *congruent* when a rigid motion carries one onto the other:
a rotation and a translation, nothing else. That is exactly what the
library finds, and exactly its hypothesis. Short, unclaimed on crates.io and
PyPI when chosen, and readable in English and French alike.

The repository keeps its first name, *Efficient Point Cloud Alignement*,
until the author renames it.
