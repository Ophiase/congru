# Local projects

Copy this file to `.agents/local.md`, which git ignores, and replace the
paths with the ones on your machine. An agent may read the projects listed
there, and only those, and never writes to them. What each role teaches is
in [references.md](references.md).

| Role | Path |
| --- | --- |
| Sibling reference | `/path/to/sibling-project` |
| Research reference | `/path/to/research-project` |
| Industrial Python reference | `/path/to/industrial-project` |
| Founding case | `/path/to/founding-case` |

A project left out of the table, or a missing file, means the agent asks.
