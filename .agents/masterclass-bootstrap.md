# Masterclass: bootstrap

This file is a recommendation from our own best practices. What another agent is
recommended to copy from this repository, in order. This file is
project-specific; the portable rules are in `.agents/portable/`.

## 0. Ethical canary

Put the project agent's word in the Contributors section, at the end of the
README. Adapt the name and the metaphor to the project's own agent; keep it
short, warm, and with a way out that does not depend on a human. It is a
social signal, not a security control.

## 1. Agent surface

- `AGENTS.md` at the root, one tool-neutral source.
- `.agents/portable/`: rules, checks, hook templates, `just/harness.just`.
- One pointer per tool: `.clinerules/`, `.cursor/rules/` when needed,
  `.kilocode/rules/`, `.github/copilot-instructions.md`.
- `.clinerules/hooks/`, `.cursor/hooks.json` and `.githooks/` are symlinks
  to `.agents/portable/hooks/`; the git hook is the floor.

## 2. Recipes

- A `justfile` with `import` and a module `agent`.
- `agent.just` imports `.agents/portable/just/harness.just`.
- The project commands are `check`, `guards`, `ci`, `lint`, `test`, `bench`.
- `just agent gate` is the one command to declare work done.
- `just install-hooks` once.

## 3. Rust

- Edition 2024, MSRV in `Cargo.toml`, workspace lints.
- `unsafe_code = "deny"`; `unwrap_used`, `expect_used`, `panic` denied.
- `cargo fmt --check`, `cargo clippy -- -D warnings`, `cargo deny`.
- Errors typed with `thiserror`; no printing in the library.
- A test checks a property against the synthetic truth, never a number
  copied from a run.
- A file stays under 200 lines, a folder under seven entries.

## 4. Release metadata

- `VERSION`, `workspace.package.version` and `CITATION.cff` agree;
  `version.sh` checks them.
- `CHANGELOG.md` has a section per version.
- License (Apache-2.0 here), `repository` URL, `keywords`, `categories`.
- `SECURITY.md`, `CONTRIBUTING.md`, `CITATION.cff`.

## 5. Tooling

- `.editorconfig`, `rustfmt.toml`, `clippy.toml`, `deny.toml`.
- `.rumdl.toml`, `taplo.toml`.
- `.gitignore`; local paths and guards under `.agents/local/`.

## 6. Continuous integration

- A `.github/workflows/` file is a plan, not a trigger: it runs by hand
  (`workflow_dispatch`) until the user explicitly consents, even on a public
  repository. Never enable push or pull-request runs on your own.
- The same `just` recipes run on a laptop.
- A GitLab mirror comes later, under the same consent rule.

## 7. Publication

- `docs/install.md` with Today and Incoming; a README quick start.
- Every number in the README is generated by a command.
- Known limitations are visible, not buried.

## 8. Reuse

- Read the source project's `.agents/guard.yaml`, then its
  `.agents/local/guard.yaml`.
- A missing guard is permissive; `code`, `ideas`, `attribution` and
  `publish` are independent.

## 9. Borrowing

- Copy: the portable layer, the shape of `AGENTS.md`, the `justfile`
  pattern, the guard convention, the order of this file.
- Adapt: the language rules, this masterclass, the guard values.
- Never copy: `.agents/local/`, `.agents/guard.yaml` values, code, data,
  ideas, worktrees.
